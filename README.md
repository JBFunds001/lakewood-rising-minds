# Lakewood Rising Minds — Homepage Concept

A homepage redesign concept for Lakewood Rising Minds, a youth nonprofit.
Designed and built by Joseph Bisayo.

- Plain HTML, CSS and JavaScript, with no build step
- Responsive desktop and mobile layouts, including a mobile menu
- Scroll and load animations, with a reduced-motion fallback
- Interactive donation picker (one-time or monthly) and a contact form with topic selection
- Optimised WebP images

Program details, donation amounts and impact lines are sample content, to be replaced with the organisation's own.
Supporting photos are from Unsplash (free to use under the Unsplash License).

## Run locally

Open `index.html` in a browser.
